# Рой — Собиратель (Swarm: Collector)

## 1. Концепт

3D-аркада на базе эмерджентного поведения (алгоритм Boids). Игрок управляет **лидером** — светлой сущностью-магнитом, которая притягивает свободных существ. Боиды изначально разбросаны по карте хаотичными кластерами, и задача игрока — собрать как можно больше из них в стаю и провести через **портал**.

**Ключевая идея:** Из простых локальных правил возникает глобальный порядок. Свободные боиды парят inertно, но при приближении лидера «оживают» и встраиваются в стаю. Чем точнее проведёшь рой через центр портала — тем выше бонус.

**Жанр:** Аркада / головоломка от третьего лица.

---

## 2. Сеттинг и визуальный стиль

**Ночное пространство** — абстрактные техногенные сущности разных цветов дрейфуют в тёмном космосе. Лидер светится ярче всех, оставляя за собой trail. При сборе роя создаётся эффектное светящееся облако из десятков разноцветных точек.

**Визуальные референсы:**
- Стая светлячков в ночном лесу, но техногенная версия
- Пчелиный рой с разными типами пчёл
- Игра Osmos (геймплей «поглощай и расти»)

---

## 3. Цветные сущности

Существа на карте делятся на **5 типов** по цвету. Все типы ведут себя одинаково в составе стаи, но визуально отличаются, создавая красивое разноцветное облако при сборе.

| Тип | Цвет | Emissive | Описание |
|-----|------|----------|----------|
| Нейтрон | Голубой `#55eeff` | `#33bbdd` | Базовый тип, самый частый (~40%) |
| Ион | Фиолетовый `#bb66ff` | `#8833cc` | Быстрее реагирует, чуть быстрее (~25%) |
| Фотон | Золотой `#ffcc33` | `#cc9900` | Светится ярче, даёт бонус при прохождении портала (~15%) |
| Электрон | Зелёный `#55ff88` | `#33cc55` | Меньше размером, плотнее группируется (~10%) |
| Кварк | Розовый `#ff66aa` | `#cc3377` | Редкий, крупнее, даёт максимальный бонус (~10%) |

**Бонусы по типу** при прохождении портала:
- Нейтрон: 1 очко
- Ион: 1 очко
- Фотон: 2 очка
- Электрон: 1 очко
- Кварк: 3 очка

**Рендеринг:** Все типы в одном InstancedMesh, цвет задаётся через `instanceColor` (Three.js). Лидер — белый с усиленным свечением, отдельный Mesh.

## 4. Управление

### 4.1 Принципы (без инверсий камеры)

Главное требование — камера **никогда не переворачивается**. Пользователь не должен терять ориентацию «где верх».

| Ввод | Действие |
|------|----------|
| Тач (левая часть экрана) / мышь | Направление полёта лидера — **относительно текущего взгляда**, не абсолютное |
| Колёсико / pinch | Зум камеры |
| Тач (правая часть) / свайп вверх | Буст ускорения |
| Тач/клик (свободная зона) / клавиша Space | Буст ускорения |

### 4.2 Детали реализации

**Относительный ввод:** Вектор от начальной точки касания определяет направление *в плоскости экрана*, затем трансформируется в мировые координаты через текущую матрицу камеры. Это гарантирует, что «вправо» всегда вправо на экране.

**Камера:**
- Позиция: за спиной лидера, offset `(0, -dist, -height)` в локальных координатах лидера
- Персистентный up-вектор камеры плавно интерполируется к мировому `(0,1,0)` — камера не кувыркается
- Питч ограничен ±50° от горизонта
- Ролл плавно затухает к нулю
- Следование через lerp (CAM_LERP = 4.0) — при резких поворотах камера «отстаёт»

**Лидер:**
- Постоянная скорость (LEADER_SPEED = 5.0), буст ×1.8 на 2 секунды с кулдауном 5 секунд
- Максимальная скорость поворота (LEADER_MAX_TURN_RATE = 3.0 рад/с)
- Инерция — плавное сглаживание velocity через lerp

**Десктоп:** WASD / стрелки для направления, Space для буста, колёсико для зума.

## 5. Основные механики

### 5.1 Поведение стаи (Boids 3D)

Каждое существо следует правилам Boids:

| Правило | Описание | Радиус | Вес |
|---------|----------|--------|-----|
| Separation | Избегать столкновений с соседями | 2.0 | 4.0 |
| Alignment | Совпадать по направлению с соседями | 10.0 | 1.7 |
| Cohesion | Двигаться к центру массы группы | 10.0 | 0.6 |
| Leader follow | Притяжение к лидеру (trail point) | 20.0 | 1.8 |
| Leader align | Выравнивание с направлением лидера | — | 0.5 |
| Boundary | Мягкое отталкивание от границ мира | — | 0.5 |

**Оптимизация:** Spatial hashing (ячейки 8 единиц) — O(n) поиск соседей вместо O(n²).

### 5.2 Сбор роя

- Свободные боиды дрейфуют инертно с минимальной скоростью (0.5–1.0), слегка покачиваясь
- При попадании лидера в **радиус привлечения** (12 единиц) свободный боид получает силу притяжения к лидеру
- Когда боид достигает расстояния `leaderTrailDist` (5 единиц) от точки следования за лидером — он считается **собранным** и начинает участвовать в правилах Boids
- Собранные боиды полностью следуют правилам стаи

### 5.3 Портал

- Светящееся кольцо (TorusGeometry) с анимацией вращения
- При приближении собранного боя к порталу (dist < 3) — он засчитывается как **прошедший** и исчезает с эффектом вспышки
- **Бонус за точность:** центр портала (dist < 1.5) даёт ×2 очки. Это стимулирует аккуратное проведение
- HUD показывает: «Собрано: 45/80 | Проведено: 12/80 | Очки: 18»

### 5.4 Препятствия (фаза 3)

- Тёмные цилиндры/призмы, разбросанные по карте
- Свободные боиды огибают их
- Собранный рой через rule Separation тоже огибает
- При столкновении лидера с препятствием — отскок + потеря 1-3 ближайших боидов (рассеиваются)

### 5.5 Зоны опасности (фаза 3)

- Красные светящиеся сферы, патрулирующие по маршруту
- Боиды в радиусе 10 единиц получают усиленный Flee
- При контакте с лидером — теряются боиды (вспышка, −5 из стаи)

## 6. Структура уровня

Каждый уровень — ограниченный **3D-объём** (куб WORLD_HALF_SIZE = 80):

```
┌─────────────────────────────────┐
│  ★  ★     ★         ★   ★     │  ← свободные боиды (кластеры)
│       ★★  ★    ██    ★  ★     │
│  ★      ★       ██      ★     │  ← препятствия (██)
│    ★★    ★    ◉◉◉◉    ★★     │  ← портал (◉◉◉◉)
│  ★     ★★        ★      ★     │
│     ★       ★★       ★   ★   │
│  ★   ★     ★    ★   ★★    ★  │
│              ▲ лидер            │
└─────────────────────────────────┘
```

**Порядок раунда:**
1. Лидер появляется в стартовой точке, вокруг — несколько собранных боев (5-10)
2. Свободные боиды распределены по карте кластерами (3-10 штук в группе)
3. Игрок летает по карте, собирая рой (притяжение при приближении)
4. Когда собрано достаточно — ведёт к порталу
5. Боиды, прошедшие через портал, засчитываются
6. Таймер раунда: 60–120 секунд (по уровням)
7. Итог: очки = сумма бонусов за проведённых боев

```typescript
// Один InstancedMesh на всю стаю
const geometry = new ConeGeometry(0.2, 0.8, 4);
const material = new MeshStandardMaterial({
  vertexColors: true,        // ← включить instanceColor
  emissive: 0x55eeff,

  metalness: 0.7,
  roughness: 0.2,

const mesh = new InstancedMesh(geometry, material, MAX_BOIDS);
mesh.frustumCulled = false; // ← критично!

// Цвет по типу

  neutron:  new Color(0x55eeff),
  ion:      new Color(0xbb66ff),
  photon:   new Color(0xffcc33),
  electron: new Color(0x55ff88),
  quark:    new Color(0xff66aa),
};
mesh.setColorAt(i, colors[boid.type]);
mesh.instanceColor.needsUpdate = true;
```

### 8.4 Камера (без инверсий)

```typescript
// Персистентный up-вектор — плавно возвращается к (0,1,0)
const persistentUp = new Vector3(0, 1, 0);

function updateCamera(leader, dt) {
  const leaderQuat = new Quaternion(leader.qx, leader.qy, leader.qz, leader.qw);

  // Позиция: за лидером
  const offset = new Vector3(0, -zoomDist, -zoomHeight);
  offset.applyQuaternion(leaderQuat);
  const targetPos = offset.add(leader.position);
  smoothCamPos.lerp(targetPos, Math.min(CAM_LERP * dt, 1));

  // Up-вектор: интерполяция к мировому (0,1,0)
  persistentUp.lerp(new Vector3(0, 1, 0), Math.min(2.0 * dt, 1));
  persistentUp.normalize();

  camera.position.copy(smoothCamPos);
  camera.up.copy(persistentUp);
  camera.lookAt(smoothLookTarget);
}
```
