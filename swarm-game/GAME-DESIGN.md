# Рой (Swarm)

## 1. Концепт

Прототип 3D-игры на базе эмерджентного поведения (алгоритм Boids). Игрок управляет **вожаком стаи** — одним существом среди сотен таких же. Остальные следуют правилам разделения, выравнивания и сцепления, но испытывают усиленное притяжение к вожаку. Камера закреплена за спиной лидера от третьего лица.

**Ключевая идея:** Из простых локальных правил возникает глобальный порядок. Стаи формируются, распадаются, огибают препятствия — без единого глобального координатора.

**Жанр:** Экшен-аркада / симуляция с элементами исследования.

---

## 2. Сеттинг и визуальный стиль

**Ночное небо** — рой абстрактных технических сущностей, похожих на реактивные ракеты или мини-дроны. Они живые, но техногенные — острые формы, реактивные хвосты, свечение движителей. Рой летит через ночное пространство, подсвечивая путь.

**Визуальные референсы:**
- Стая ракет/дронов в ночном небе
- Пчелиный рой, но техногенный
- Трейлер фильма «Аквамен» (стая人与)

## 3. Основные механики

### 3.1 Управление вожаком

- **Виртуальный джойстик** (левый пальца) — направление движения вожака
- На **десктопе**: WASD или стрелки + мышь для обзору
- Вожак имеет **инерцию** — не может резко развернуться, поворот плавный (maxTurnRate)
- Вожак двигается с постоянной скоростью (speed), с возможностью ускорения (boost)

### 3.2 Поведение стаи (Boids 3D)

Каждое существо в стае (boid) следует стандартным правилам, расширенным в 3D:

| Правило | Описание | Радиус |
|---------|----------|--------|
| **Separation** | Избегать столкновений с ближайшими соседями | 2.0 |
| **Alignment** | Совпадать по направлению с соседями в зоне восприятия | 5.0 |
| **Cohesion** | Двигаться к центру массы своей группы | 8.0 |
| **Leader follow** | Усиленное сцепление к вожаку (×3 вес) | 15.0 |
| **Boundary** | Мягкое отталкивание от границ уровня | — |

**Оптимизация:** Spatial hashing (кубические ячейки размером ~5 единиц) — вместо O(n²) поиск соседей за O(n).

**Проблема границ:** Вместо wrap-around (который выглядит неестественно), использовать мягкие стены — сила отталкивания нарастает при приближении к границе мира.

### 3.3 Камера

- Камера **за спиной вожака**, смещение: (0, 2, -6) относительно вожака
- Плавное следование через lerp (как в starflow-3d, SMOOTH_CAM_LERP = 3.5)
- Лёгкий look-at: камера смотрит не точно на вожака, а на ~1 единицу перед ним
- При быстром повороте — камера слегка «отстаёт», создавая динамичность
- Pinch-to-zoom для приближения/отдаления (мобильные устройства)

### 3.4 Структура уровня

Каждый уровень — ограниченный **3D-объём** (прямоугольная область):
- Начало: вожак и стая появляются в одной точке
- Цель: провести **80%+ стаи** через **портал выхода** (светящееся кольцо)
- На пути: препятствия, хищники, сборные предметы

**Портал:**
- Два параллельных светящихся кольца, вращающихся навстречу друг другу
- При приближении существа засчитываются как «прошедшие»
- Счётчик «12/50 прошли» отображается над порталом
- Эффект: частицы втягиваются внутрь при прохождении

## 4. Типы объектов

### 4.1 Существа (Boids)

**Рендеринг:** `InstancedMesh` — одна геометрия на всю стаю, один draw call.

**Геометрия:** Абстрактная «ракета/дрон»:
- Тело: ConeGeometry (0.15, 0.5, 4) — заострённая форма
- Свечение: `MeshStandardMaterial` с emissive (цвет движителя)
- Реактивный хвост: небольшой trail за каждым boid
- Для вожака: слегка увеличенная модель + brighter emissive

**Материал:**
- `MeshStandardMaterial` с emissive (свечение движителя)
- Цвет стаи — единый на уровне, но с лёгкой случайной вариацией по инстансам
- При потере энергии — угасание свечения

**Хвост-шлейф:**
- Для каждого boid хранятся последние N позиций
- Рендеринг через `Line` или `BufferGeometry` с обновлением
- Оптимизация: не для всех boids — только для ближайших к камере (20-30 штук)

**Post-processing:** UnrealBloomPass для эффекта свечения (залипающее свечение движителей) — максимальная зрелищность.

### 4.2 Препятствия

- Скалы/столбы из тёмного материала
- Цилиндры или неправильные формы (DodecahedronGeometry)
- Boids огибают их через дополнительное правило **Obstacle avoidance** (raycast вперёд, разворот при обнаружении)

### 4.3 Хищники

- 2-4 крупных существа красного цвета, патрулирующих зону
- Правило **Flee**: boids в радиусе 10 единиц от хищника получают усиленный separation
- Хищники двигаются по предопределённому маршруту (path)
- При столкновении хищника с boid — boid «теряется» (исчезает с анимацией вспышки)
- Поражённые boids уменьшают счётчик стаи

### 4.4 Энергетические частицы

- Маленькие золотистые шарики, рассыпанные по уровню
- При сборе (boid пролетает рядом) — восполняют «энергию» стаи
- Энергия нужна для boost-ускорения вожака
- Визуальный эффект: частица «втягивается» в ближайшего boid

### 4.5 Вихри (опционально, для усложнения)

- Зона закручивающегося потока (toroidal force field)
- Boids внутри вихря получают дополнительную боковую силу
- Визуально: вращающиеся частицы/линии

### 6.3 Spatial Hashing (оптимизация)

Пространство разбивается на кубические ячейки размером `cellSize = 5`:

```typescript

  key(x: number, y: number, z: number): string {
    const cx = Math.floor(x / cellSize);
    const cy = Math.floor(y / cellSize);
    const cz = Math.floor(z / cellSize);
    return `${cx},${cy},${cz}`;
  }

  query(x: number, y: number, z: number, radius: number): BoidData[] {
    // Проверить ячейки в радиусе radius / cellSize
    // Вернуть всех boids в соседних ячейках
  }
}
```

Сложность поиска соседей: O(n) вместо O(n²).

### 6.4 InstancedMesh

Один draw call на всю стаю:

```typescript
const geometry = new ConeGeometry(0.15, 0.5, 6);
const material = new MeshStandardMaterial({
  emissive: swarmColor,
  emissiveIntensity: 0.8,
  transparent: true,
  opacity: 0.9,
});
const mesh = new InstancedMesh(geometry, material, MAX_BOIDS);

// Каждый кадр:
const matrix = new Matrix4();
for (const boid of boids) {
  matrix.compose(
    new Vector3(boid.x, boid.y, boid.z),
    new Quaternion().setFromUnitVectors(UP, boid.dir),
    new Vector3(1, 1, 1)
  );
  mesh.setMatrixAt(i, matrix);
}
mesh.instanceMatrix.needsUpdate = true;
```

### 6.5 Виртуальный джойстик

- Область активации: левая половина экрана
- Палец вниз → фиксируется центр джойстика
- Движение пальца → вычисляется вектор (dx, dy)
- Длина вектора ограничена maxRadius → скорость вожака
- Визуально: полупрозрачный круг + стик

## 8. Отличия от starflow-3d

| Аспект | Star Flow 3D | Swarm: Вожак |
|--------|-------------|--------------|
| Камера | Орбитальная (свободная) | От третьего лица (за лидером) |
| Геймплей | Стратегия (походы, захват) | Аркада (проведи стаю) |
| Объекты | 20-30 сфер | 200+ instanced mesh |
