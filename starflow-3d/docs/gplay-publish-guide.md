## 1. Обзор требований Google Play

Google Play Console требует заполнить несколько обязательных разделов перед отправкой приложения на ревью. Для Star Flow все эти требования достаточно стандартные, но есть нюансы, связанные с рекламой и платежами.

### Обязательные разделы GPlay Console:

| Раздел | Статус для Star Flow | Сложность |
|--------|---------------------|-----------|
| Store Listing (описание, скриншоты) | Обязательный | Средняя |
| Content Rating (возрастной рейтинг) | Обязательный | Низкая |
| Target Audience | Обязательный | Низкая |
| Privacy Policy | Обязательный (есть реклама) | Низкая |
| Ads declaration | Обязательный (есть реклама) | Низкая |
| App Content (разделы) | Обязательный | Средняя |
| Billing declaration | No (нет покупок) | Низкая |
| App access (разрешения) | Обязательный | Низкая |

## 2. Сторонние платёжные системы — анализ

### Текущая ситуация (май 2026)

С 2024 года Google Play постепенно открывал возможность использования сторонних платёжных систем в результате антимонопольного законодательства:

- **ЕЭЗ** — DMA (Digital Markets Act) обязал Google разрешить альтернативные платежи
- **США** — Решение суда Epic Games v. Google обязало Google открыть платёжную систему
- **Март 2026** — Глобальная реформа комиссий Google Play

### Комиссии Google Play (с марта 2026)

| Тип транзакции | Сервисный сбор Google | Сбор за обработку |
|----------------|----------------------|-------------------|
| Покупки в приложении | 20% / 15% | +5% (Google Play Billing) |
| Подписки | 10% | +5% (Google Play Billing) |
| Сторонний платёж (в приложении) | 20% / 9% (косметика) | Провайдер (~2-3%) |
| Внешние ссылки | 20% / 9% (косметика) | Провайдер (~2-3%) |

### Региональные программы

| Регион | Сторонние платежи | Требуется API Google | Итоговая комиссия |
|--------|-------------------|---------------------|-------------------|
| **ЕЭЗ** | User Choice Billing | Да (Alternative Billing API) | ~18.5% (скидка 4%) |
| **США** | Alternative Billing | Да | ~27.5% (дороже Google Play!) |
| **UK** | User Choice Billing | Да | ~18.5% |
| **Остальной мир** | Нет | — | 25% (Google Play Billing) |

### Рекомендация для Star Flow

**Не использовать сторонние платежи на Google Play.** Причины:

1. **Экономика невыгодна** — в США альтернативный платёж (~27.5%) дороже Google Play Billing (25%). Только в ЕЭЗ есть выгода (~18.5% vs 25%), но это требует интеграции Alternative Billing API и дополнительных экранов согласия.

2. **Технические затраты** — интеграция Alternative Billing API требует: экран информирования пользователя, поддержка родительского контроля, отчётность о транзакциях, обработка возвратов. Для инди-проекта это неоправданно.

3. **Юридическая неопределённость** — settlement Epic v. Google ещё на утверждении, комиссии могут измениться.

4. **Объём продаж** — при небольших объёмах разница в 5-7% минимальна, а затраты на поддержку двух платёжных систем — постоянные.

### Вывод

**Текущий подход Star Flow (YooKassa через внешнюю ссылку для RuStore)** отлично работает для RuStore. Для Google Play — скрыть кнопку магазина через флаг сборки `VITE_ENABLE_SHOP=false`. Если в будущем потребуется монетизация на GPlay, лучше интегрировать Google Play Billing (один раз, по стандарту), чем костылять альтернативные платежи.

| **Horror** | None | Нет элементов хоррора |

## 5. Политика конфиденциальности (Privacy Policy)

**Файл:** `docs/PRIVACY_POLICY.md` в репозитории

**URL для GPlay:** `https://github.com/NikasAl/starflow/blob/main/docs/PRIVACY_POLICY.md`

Подробный текст политики конфиденциальности подготовлен отдельно. Ключевые моменты:

- Приложение **не собирает** персональные данные
- Рекламный SDK (Яндекс Ads) может собирать данные для таргетирования (описано в политике)
- Платёжная система (YooKassa, только RuStore) обрабатывает данные согласно ФЗ-152 и политике YooKassa
- Данные хранятся локально на устройстве (localStorage: прогресс, настройки, ID устройства)
- Контакт: nika.saratov@yandex.ru (заменить на актуальный)
- Хостинг в GitHub — публичный, соответствует требованиям открытого исходного кода

| Поле | Ответ |

- Рекламный блок R-A-XXXXXX (заменить на реальный при публикации)
- Яндекс Ads SDK автоматически обрабатывает рекламный ID

## 7. Правила встроенных покупок (Billing)

### Положение для Google Play

В сборке для Google Play кнопка магазина **скрыта** через флаг `VITE_ENABLE_SHOP=false`. Это означает:

- В приложении **нет цифровых покупок**
- Нет необходимости декларировать billing
- Монетизация только через рекламу (rewarded ads)
- Пакет: `ru.kreagenium.starflow` (такой же, как в RuStore)

> Для RuStore доступна версия с магазином энергии через YooKassa (отдельная сборка с `VITE_ENABLE_SHOP=true`), но это не касается GPlay.

## 8. Разрешения Android

В GPlay Console: **App content → App access**

### Разрешения Star Flow

| Разрешение | Необходимость | Обоснование для GPlay |
|------------|--------------|----------------------|
| `INTERNET` | Обязательно | Сетевая игра, реклама, обновления |
| `ACCESS_NETWORK_STATE` | Обязательно | Проверка доступности сети |

Проверить фактические разрешения в `AndroidManifest.xml`:

```bash
cd android && grep -r "uses-permission" app/src/main/AndroidManifest.xml
```

### Важно

Каждое разрешение требует обоснования в GPlay Console. Для Star Flow оба разрешения стандартные и не вызовут вопросов.

## 10. Требования к графическим материалам

### Store Listing (Главная страница)

| Материал | Размер | Формат | Примечание |
|----------|--------|--------|------------|
| **Иконка** | 512×512 | PNG | Требуется high-res иконка |
| **Скриншот phone** | 16:9 или 9:16 | PNG/JPG | Минимум 2, рекомендуется 3-8 |
| **Скриншот tablet 7"** | 16:9 | PNG/JPG | Необязательно |
| **Скриншот tablet 10"** | 16:9 | PNG/JPG | Необязательно |
| **Скриншот TV** | 16:9 | PNG/JPG | Необязательно |
| **Промо-графика** | 1024×500 | PNG/JPG | Опционально, для рекомендаций |
| **Видео** | 30 сек, 1080p | YouTube | Опционально |

### Для Star Flow

Скриншоты можно сделать через встроенный скрипт медиа-захвата:

```bash
cd /home/z/my-project/starflow/starflow-3d
npm run capture:screenshot     # Скриншот 2560×1440
npm run capture:record         # Видео 30 сек
npm run capture:promo          # Промо-видео 15 сек
```

### Текстовые поля Store Listing

| Поле | Рекомендация |
|------|-------------|
| **Название** | Поток — Космическая стратегия (макс. 30 символов) |
| **Краткое описание** | Захватывай планеты, строи флот, побеждай! (макс. 80 символов) |
| **Полное описание** | Подробное описание на русском и английском (до 4000 символов) |

## 11. Чеклист перед публикацией

### Перед отправкой на ревью

- [ ] Собрать GPlay APK: `npm run android:gplay:release`
  - Пакет: `ru.kreagenium.starflow`
  - Подпись: release keystore (`/home/nikas/myprjs/keystore`, alias `starflow`)
  - Кнопка магазина: скрыта (VITE_ENABLE_SHOP=false)
- [ ] Загрузить APK/AAB в GPlay Console
- [ ] Заполнить Store Listing (описание, иконка, скриншоты)
- [ ] Пройти Content Rating вопросник
- [ ] Указать Target Audience
- [ ] Добавить ссылку на Privacy Policy (GitHub)
- [ ] Декларировать рекламу (Яндекс Ads)
- [ ] Обосновать разрешения Android
- [ ] Заполнить App Content sections
- [ ] Указать контактный email для GPlay
- [ ] Создать профиль разработчика (если нет) — $25 единоразово

### Версионирование

- GPlay Console автоматически управляет версиями
- `versionCode` в `AndroidManifest.xml` должен быть выше предыдущего
- `versionName` — семантическая версия (например, `1.0.0`)

### Что может задержать ревью

1. **Отсутствие Privacy Policy** — обязательно при наличии рекламы
2. **Неправильный Content Rating** — пройти вопросник заново
3. **Несоответствие скриншотов реальному приложению** — обновлять при каждом релизе
4. **Сломанная ссылка на Privacy Policy** — проверить URL перед отправкой
