## 1. Общие положения

Настоящая Политика конфиденциальности (далее — «Политика») описывает, какие данные собирает и обрабатывает мобильное приложение «Поток» (далее — «Приложение») при его использовании на устройствах пользователей. Политика составлена в соответствии с законодательством Российской Федерации, включая Федеральный закон «О персональных данных» № 152-ФЗ, а также рекомендациями Google Play для разработчиков приложений.

Приложение распространяется через RuStore и Google Play. Исходный код приложения является открытым и доступен на GitHub по адресу: https://github.com/NikasAl/starflow. Любой пользователь может ознакомиться с кодом и убедиться в том, как именно работают функции обработки данных.

Используя Приложение, вы соглашаетесь с условиями настоящей Политики. Если вы не согласны с условиями, пожалуйста, прекратите использование Приложения.

## 2. Какие данные мы собираем

### 2.1. Данные, собираемые приложением напрямую

Приложение **не требует регистрации, создания аккаунта или предоставления персональных данных**. Мы не собираем и не храняем на наших серверах следующие данные:

- Имена, адреса электронной почты, номера телефонов
- Геолокационные данные
- Фотографии, видео или файлы пользователей
- Социальные идентификаторы
- Данные платежных карт или банковских счетов

### 2.2. Локальные данные на устройстве

Приложение хранит следующие данные **исключительно на устройстве пользователя** (в локальном хранилище браузера / localStorage):

| Тип данных | Назначение | Где хранится |
|-----------|------------|-------------|
| Прогресс игры | Сохранение текущего уровня, состояния планет, энергии | localStorage |
| Язык интерфейса | Запоминание выбранного языка | localStorage |
| Уникальный ID устройства | Идентификация при платёжных операциях (YooKassa, только версия RuStore) | localStorage |
| Вспомогательные флаги | Отметки о просмотренном обучении, отложенных платежах | localStorage |

Эти данные **не передаются на наши серверы** (за исключением ID устройства при совершении платежа в версии RuStore, см. раздел 3). Данные хранятся на устройстве до удаления приложения или очистки данных приложения в настройках Android.

### 2.3. Данные, собираемые сторонними сервисами

Некоторые компоненты Приложения используют сторонние SDK, которые могут собирать данные самостоятельно. Эти процессы регулируются политиками конфиденциальности соответствующих компаний:

#### Яндекс реклама (Yandex Mobile Ads SDK)

Приложение содержит рекламный SDK Яндекс для показа рекламных объявлений (rewarded video ads — реклама за энергию в игре). Яндекс Ads SDK может собирать:

- Рекламный идентификатор устройства (Advertising ID)
- Модель устройства, версия ОС
- IP-адрес (для определения региона)
- Данные об использовании приложения для таргетирования рекламы

Подробнее: [Политика конфиденциальности Яндекс](https://yandex.ru/legal/confidential/)

## 3. Платежные данные

> **Примечание:** Версия приложения, распространяемая через Google Play, **не содержит встроенных покупок**. Этот раздел относится исключительно к версии, распространяемой через RuStore.

### 3.1. Версия RuStore

Приложение содержит магазин энергии с оплатой через платёжную систему YooKassa. При совершении покупки:

- Приложение отправляет на наш сервер (`kreagenium.ru`) только: ID устройства и сумму платежа
- Переход к оплате осуществляется через защищённое соединение (HTTPS) на страницу платёжного провайдера YooKassa
- Платёжные данные (номер карты, реквизиты) **не проходят через наше приложение** и **не хранятся на наших серверах**
- YooKassa обрабатывает платёжные данные в соответствии со стандартом PCI DSS и законодательством РФ

Подробнее: [Политика конфиденциальности YooKassa](https://yookassa.ru/legal/confidential/)

### 3.2. Версия Google Play

Магазин энергии **отсутствует**. Платежные данные не собираются и не обрабатываются. Монетизация осуществляется исключительно через рекламу (rewarded video ads).

## 4. Как мы используем данные

Собранные данные используются исключительно для следующих целей:

| Цель | Данные |
|------|--------|
| Обеспечение работы игры | Локальный прогресс, настройки |
| Показ рекламных объявлений | Данные устройства (через Яндекс Ads SDK) |
| Обработка платежей (только RuStore) | ID устройства, сумма |
| Улучшение стабильности | Технические логи (не содержат персональных данных) |

Мы **не передаём** ваши персональные данные третьим лицам для маркетинговых целей, не продаём и не публикуем их.

## 6. Безопасность данных

Мы принимаем разумные меры для защиты данных, обрабатываемых приложением:

- Все сетевые запросы выполняются по протоколу HTTPS
- Платёжные операции (RuStore) обрабатываются через сертифицированного платёжного провайдера (YooKassa, PCI DSS compliant)
- Данные прогресса игры хранятся локально на устройстве и не передаются на внешние серверы
- Исходный код приложения открыт и доступен для аудита на GitHub

## 7. Дети

Приложение может использоваться детьми. Мы сознательно **не собираем данные, позволяющие идентифицировать ребёнка** (имя, возраст, контакты). Приложение не имеет функций социальной интеграции, чатов или обмена пользовательским контентом. Рекламный SDK используется в режиме rewarded ads (просмотр по инициативе пользователя), что соответствует требованиям COPPA и аналогичного законодательства.

## 8. Права пользователя

Вы имеете право:

- **Удалить локальные данные** — через настройки Android: Настройки → Приложения → Поток → Очистить данные
- **Отключить рекламный ID** — через настройки Google: Настройки → Google → Реклама → Удалить рекламный ID
- **Отказаться от персонализированной рекламы** — через настройки Яндекс: [yandex.ru/support/partner2/ads/prefs](https://yandex.ru/support/partner2/ads/prefs)
- **Запросить информацию** — написать на nika.saratov@yandex.ru с запросом о данных, связанных с вашим устройством
- **Просмотреть исходный код** — [github.com/NikasAl/starflow](https://github.com/NikasAl/starflow)
