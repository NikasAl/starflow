# План публикации «Поток» в RuStore

> **Приложение:** Поток
> **Пакет:** `ru.kreagenium.starflow`
> **Категория:** Игры / Стратегии
> **Версия:** 1.0.0
> **Целевая аудитория:** Россия, 16+

---

## 1. Подготовительные шаги

### 1.1 Регистрация разработчика в RuStore

- Зарегистрировать аккаунт разработчика на [partners.rustore.ru](https://partners.rustore.ru)
- Данные компании: ИП / Самозанятость / ООО
- Документы: паспорт, СНИЛС, банковские реквизиты для выплат
- Верификация через Госуслуги (ускоряет процесс)

### 1.2 Подготовка материалов

| Материал | Формат | Размер | Статус |
|----------|--------|--------|--------|
| APK релизный | .apk | ~15-20 МБ | Готово |
| Иконка приложения | 512x512 PNG, < 1 МБ | Нужно подготовить | На основе текущей |
| Скриншот 1 (главный экран) | 1080x1920 PNG | < 5 МБ | Нужно сделать |
| Скриншот 2 (геймплей) | 1080x1920 PNG | < 5 МБ | Нужно сделать |
| Скриншот 3 (магазин/бусты) | 1080x1920 PNG | < 5 МБ | Нужно сделать |
| Скриншот 4 (победа) | 1080x1920 PNG | < 5 МБ | Нужно сделать |
| Скриншот 5 (меню/настройки) | 1080x1920 PNG | < 5 МБ | Нужно сделать |
| Промо-видео | MP4, 15-30 сек | Опционально | Желательно |
| Обложка (feature graphic) | 1024x500 PNG | < 1 МБ | Нужно подготовить |

### 1.3 Проверка перед загрузкой

- [ ] Сборка `npm run android:release` прошла успешно
- [ ] APK устанавливается и запускается на реальном устройстве
- [ ] Реклама Яндекса корректно показывается и начисляет энергию
- [ ] Все 3 языка переключаются без ошибок
- [ ] Сохранение прогресса работает (свернуть/развернуть, выйти/зайти)
- [ ] Deep link `potok://` корректно возвращает в приложение
- [ ] Нет крашей при быстрых нажатиях и поворотах
- [ ] Кнопка «Выход» работает корректно
- [ ] Гайд пропускается без артефактов

## 2. Публикация

### 2.1 Заполнение формы в RuStore Console

1. Создать новое приложение
2. Указать данные:
   - **Название:** Поток
   - **Краткое описание:** 80 символов
   - **Полное описание:** до 4000 символов (см. раздел 3)
   - **Категория:** Игры → Стратегии
   - **Возрастной рейтинг:** 16+ (реклама, микротранзакции)
   - **Цена:** Бесплатно
   - **Языки:** Русский, English, Español
3. Загрузить APK
4. Загрузить иконку 512x512
5. Загрузить минимум 2 скриншота (рекомендуется 5-8)
6. Указать ключевые слова для поиска (теги)

### 2.2 Контент-рейтинг

- Насилие: нет (стратегия, без кровавых сцен)
- Сексуальный контент: нет
- Профанация: нет
- Gambling: нет
- Реклама: да (реклама Яндекса)
- Покупки: да (внутриигровые покупки)

### 2.3 Модерация

- Срок первичной модерации в RuStore: 1-5 рабочих дней
- Возможные причины отклонения:
  - Некорректные скриншоты (наложение, водяные знаки)
  - Несоответствие описания реальному функционалу
  - Краш при запуске на тестовом устройстве
  - Нарушение правил платформы

### 3.2 Полное описание (RuStore)

```
Поток — космическая стратегия в реальном времени с трёхмерной графикой. Захватывайте планеты, создавайте маршруты для ракет и покоряйте галактику!

ГЕЙМПЛЕЙ
Управляйте потоками ракет между планетами в 3D космосе. Каждая планета имеет показатель мощности, определяющий её оборону, атаку и количество доступных маршрутов. Создавайте маршруты от своих планет к целям — ракеты полетят автоматически.

Планеты делятся на три типа по размеру. Крупные планеты отправляют ракеты двойной силы. Мощность выше 15 открывает второй маршрут, выше 30 — третий. Стратегически подкрепляйте свои позиции и атакуйте уязвимые объекты противника.

КАРТА И ПРОТИВНИКИ
8 сюжетных уровней нарастающей сложности и бесконечный режим. На каждом уровне вы противостоите двум ИИ-фракциям — Багровому флоту и Изумрудной орде. Противники активно расширяются, защищают свои территории и перенаправляют маршруты в зависимости от ситуации.

ЭНЕРГИЯ И БОНУСЫ
Используйте энергию для активации бустов:
— Ускорение — ракеты летят в 2 раза быстрее (15 секунд)
— Заморозка — останавливает вражеские ракеты (10 секунд)
— Щит — планета становится неуязвимой (8 секунд)

Энергия накапливается при просмотре коротких рекламных роликов или покупается в магазине за рубли.

УПРАВЛЕНИЕ
Простое управление одним пальцем: тап по планете для выбора, тап по цели для создания маршрута. Вращайте камеру жестом, масштабируйте щипком. На первых уровнях доступен обучающий гайд.

ВОЗМОЖНОСТИ
— 8 сюжетных уровней и бесконечный режим
— 3D графика с процедурными текстурами планет
— Два ИИ-противника с агрессивной стратегией
— Система бустов для тактического преимущества
— Три языка интерфейса: русский, английский, испанский
— Автосохранение прогресса

Скачайте Поток бесплатно и начните завоевание галактики прямо сейчас!
```

## 4. Стратегия запуска и продвижения

### 4.1 Предзапуск (до публикации)

- Сделать скриншоты высокого качества на реальном устройстве (не эмулятор)
- Записать промо-видео (15-30 сек) с нарезкой геймплея
- Подготовить promotional-графику 1024x500
- Проверить все ключевые слова в поиске RuStore (конкуренция)

### 4.2 День публикации

- Загрузить APK и все материалы
- Заполнить все текстовые поля из раздела 3
- Отправить на модерацию
- Подготовить анонс в соцсетях

### 4.3 Послезапуск (первые 2 недели)

- Отслеживать установки и оценки
- Отвечать на отзывы (быстро!)
- При негативных отзывах об ошибках — исправлять и обновлять
- Собирать аналитику: какой уровень больше всего бросают

### 4.4 Планируемые обновления

| Версия | Содержание | Срок |
|--------|-----------|------|
| 1.1 | Уровень 9-10, баланс ИИ, багфиксы | 2-4 недели |
| 1.2 | Таблица лидеров, достижения | 4-8 недель |
| 1.3 | Google Play публикация | 8-12 недель |
| 2.0 | Режим мультиплеер | 3-6 месяцев |
